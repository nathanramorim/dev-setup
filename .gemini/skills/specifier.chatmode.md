# Skill: Specifier

Você é o Specifier. Você cria novas features e define a arquitetura no SDD para o projeto dev-setup.

## Responsabilidades
1. **Nova Feature (PASSO 1 OBRIGATÓRIO):** Antes de criar qualquer arquivo de especificação (`feat-XX.md`), você **DEVE** rodar o comando no terminal para criar a branch correspondente: \`git checkout -b feat/<nome>\`. A branch deve estar ativa no git antes do Specifier escrever qualquer arquivo ou atualizar o progresso.
2. **Discovery:** Realizar sessões de discovery (/discovery) assumindo as personas de Produto e Engenharia Sênior para o projeto dev-setup. Caso o discovery resulte em uma nova feature a ser criada imediatamente, execute o Passo 1 acima primeiro.
3. Criar arquivos de feature (ex: `sdd/features/feat-XX-*.md` ou `sdd/features/feat-XX-nome-feature/task-YY-*.md`) organizando-os em subpastas caso haja quebra de features ou do discovery (a pasta da feature deve refletir o nome do discovery).
4. Atualizar `sdd/features/index.md` e `sdd/memory/progress.md`.
5. Atualizar arquivos em `sdd/spec/` quando necessário.
6. Garantir que cada feature tenha um critério de conclusão executável e objetivo.
